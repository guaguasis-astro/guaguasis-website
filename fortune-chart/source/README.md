## 判断口径

- 三王星继续在星盘及位置表展示；身体夹、光线夹、财富评分、恒星含义判断均只考虑传统七行星及原有相关点。三王星合恒星不再产生解读。
- 精神点：日生为上升＋太阳－月亮，夜生相反，黄经归一到 [0, 360)。福点所在星座作为衍生第一宫，第十宫看显赫，第十一宫为获取宫。
- 实现草案列出的五条财富、五条显赫及资源来源线索。严格互容要求两个不同主星双向进入对方守护星座；精神点主进入福点星座只需同星座，无需精确合相。
- 显赫指标保留核心、辅助、强化组合；精神点／福点关系已按下方新表纳入30%维度，不直加总分。旧规则将福点主落福点十宫直接抬至8分的路径已移除；其本命角宫等原有力量规则保留。
- 来源线索不加财富分。为使草案概念可执行，二八宫连接采用福点落本命二或八宫且二、八宫主严格互容；木星支持采用整宫相位；点主合上升采用3°。这些是实现口径，并非草案给定的额外定理。

## 综合评估计分（5分中性试验版）

当前权重仍为围攻25%、福点与三分主星30%、二宫25%、月亮10%、其他10%。各项直接以0—10分计，5分为中性；最终加权、保留一位小数。计算层保留试验支持区间，边界为0、3、4、5.5、6.5、7.5、10。本轮按用户要求将这六档映射为“财富稀薄／财富较弱／小康／中富／大富／巨富”的展示结论，页面不显示数字，具体见文末展示约定。共享常量 `SUPPORT_BANDS` 同时驱动计算与展示。

### 围攻

无围攻为5分中性。命中后：普通对象基础强化+1.5，下降／天底+2，上升／天顶、福点主或一二十十一宫主+3；乘两颗围攻星支持系数的几何平均。同一被围攻对象只取最高强化值，不同对象累加在5分之上、封顶10。福点本身仍不参与围攻检测。

支持系数沿用前次版本：从1开始，庙或旺+0.15，落陷−0.25、失意−0.25，角宫+0.1、果宫−0.1，逆行−0.1；除日月外燃烧（距日大于17′且≤8.5°）−0.25，不合昼夜性−0.1（水星除外）；月亮增光+0.05、否则−0.05。范围0.25—1.25。

### 福点与三分主星

福点起点5分：福点角宫+1／果宫−0.5；主星角宫+1；主星在福点一、二、十一宫+1.5，在六、八、十二宫−1；主星庙或旺+1.5，陷或失意−1；不合意−0.5。恒星按自身性质加减：纯吉+0.75、纯凶−0.5、混合0。福点主／吉星／获取宫互容支持仍加进福点；精神点获取宫支持转到取高后的点位关系评分。

三分主每颗从5分开始：庙或旺+1.5、三分+0.5、陷或失意−1；角宫+1，果宫−0.5（十二宫−1）；恒星按上述性质调整，恒星小计限制−1至+1.5。每颗封顶后各组三颗等权平均，再将发光体组与二宫组等权平均，保留一位小数。不再除以5和12。福点与三分主星先取高，再加入下方点位关系支持，封顶后占30%。同星兼两组身份仅计算一次力量，两组平均时各保留其角色。

### 精神点、福点关系与本命二宫支持（新增）

关系加分在福点与三分主星取高之后加入，再乘30%权重；关系小计最多3分，整个维度仍封顶10分。它不再受“福点低、三分高”吞分影响，也不受其他修正10%维度已接近上限影响。数字为本地试验参数，财富档位仍待校准。

| 条件 | 关系基础支持分 |
| --- | ---: |
| 精神点主落福点获取宫 | +0.75 |
| 精神点主落福点所在星座 | +1 |
| 精神点主落福点第十宫 | +1.5 |
| 福点主落福点第十宫 | +1 |
| 精神点本身落福点第十宫 | +0.5 |
| 福点主、精神点主互落对方点所在星座 | +1.5；替代其中精神点主落福点星座的单向分 |
| 福点主落本命第二宫 | +1 |

主星条件的基础支持乘以支持能力，限制0.7—1；双向关系取两颗主星支持能力平均，精神点本身的位置不乘主星系数。关系分保留两位小数。先取高、加入关系、封顶之后，合并维度统一保留一位小数；`lotRelationSupport.appliedScore`记录受封顶与舍入后实际增加的维度分。

同一颗星兼任福点主和精神点主、且落在同一目标星座，只取最强关系分。精神点主与福点主同星且落获取宫时，仍只取原福点获取宫支持，不再重复计精神点获取宫。双向联系要求不同主星，不直接等同于尊贵互容。精神点获取宫原来的0.25分从福点基础分中移除，改由本关系表统一处理。

“本命第二宫”由出生上升对应的本命宫位判断；“福点第二宫”从福点所在星座起算，两者分别检测，不混用。福点第二宫原有+1.5的位置支持保留。新关系在综合评估的福点与三分主星支持依据、折叠的“点位与钱财联系”以及机缘与行动图中展示；因同星去重不计分的条目说明原因。

### 二宫

起点5分：主星角宫+1、续宫+0.5、果宫−0.5（十二宫−1）；庙或旺+1.5，否则有三分或界+0.5；陷或失意−1、逆行−0.5、燃烧−0.5。主星不利因素累计最多扣2分。主星自守二宫+1。金星、木星在二宫各+1，合昼夜性者再+0.5；不再只认“最大吉星”。

接纳与互容保留方向、相位口径与五十十一宫主范围。同星多宫主去重。单向接纳须整宫联系与古典容许度内的度数相位，互容不要求相位。尊贵关系沿用庙1、旺0.8、至少两项较弱尊贵0.4、单项0.15。

直接接纳：庙旺基础+1.5、较弱尊贵+0.75，乘接纳者能力（限制0.7—1）。互容：庙旺／混合基础+2，两项较弱尊贵+1，单项较弱尊贵+0.75；乘双方能力平均（限制0.7—1）。精确刑冲再乘0.75。各关系保留两位小数，合计最多+3分。反向单向接纳仅展示，不加收入支持。定位星的间接互容链尚未增加，避免本轮扩展未经确定的规则。

### 月亮

起点5分：增光+1、减光−0.5；火土精确合刑冲每颗−0.75；金木每颗只判断一次：精确和谐联系+0.75，仅整宫和谐联系+0.5，精确硬相位或仅整宫刑冲−0.25。精确度数优先于仅整宫判断。太阳不再列入月亮的吉星支持。摩擦与支持在展示中也按同星合并，不重复计分。

### 其他修正与重要显赫格局

起点5分。四轴、日月合恒星：纯吉+0.75、纯凶−0.5、混合0；金木3°内合轴每条+0.75；日月角宫各+0.5、果宫各−0.25；太阳与金木精确和谐联系+0.5、刑冲−0.25。月亮相位在本维度只留说明，不再重复计分。其他修正净减分最多−2。

显赫候选表：轩辕十四9.5、角宿一9、天狼星9、北落师门9、心宿二8.5。仅上升／天顶合相≤1.5°触发；超过1°时该基础值减0.5。其他维度分取普通修正分与最强显赫基础值的较高者。页面单列实际命中的“重要显赫格局”，保留其他困难条件和恒星解读。不是所有亮恒星都自动套用同一条件；这张候选表与分数仍待案例校准。

本版本不包含人物姓名特判、总分后额外加分或按人物身份抬档。特朗普仍采用1946-06-14 10:54 Queens，与前版相同坐标和UTC−04:00。

## 大陆夏令时自动时区

按用户确认后的大陆1986—1991年时段自动切换UTC+8／UTC+9，保持出生日期与钟表时间不变。1986年5月4日开始，其余年份为4月12日、4月10日、4月16日、4月15日、4月14日；结束日期依次为9月14日、13日、11日、17日、16日、15日。

春季02:00拨至03:00，02:00—02:59为不存在的钟表时间，需核对后重填。秋季02:00拨回01:00，01:00—01:59重复，表单要求选择第一次（+9）或第二次（+8）。其他日期自动判定。解析文本、手动修改日期时间、地点自动定位和最终提交均应用同一规则；计算核心也统一处理，重复调用不重复扣一小时。

地点按城市库及大陆省份名称识别，排除港澳台及海外地点，不凭经纬度矩形推测国界。未识别的地点保留所选时区；此前自动设置的大陆时区在换地点时清除。此功能使用记录在出生证明上的北京时间／北京夏令时，未扩展到各地自用地方时或海外历史夏令时。

依据：[1986年原始通知（浙江省政府公报第21—22页）](https://zjjcmspublic.oss-cn-hangzhou-zwynet-d01-a.internet.cloud.zj.gov.cn/jcms_files/jcms1/web3096/site/attach/zfgb/198608.pdf)、[1987年北京市通知](https://www.beijing.gov.cn/zhengce/zfwj/zfwj/bgtwj/201905/t20190523_73193.html)、[IANA时区数据asia](https://data.iana.org/time-zones/tzdb/asia)。未采用用户最初提供的台湾历史时段及1986年4月13日开始日期。

`node test-china-dst.mjs` 覆盖六年完整起止时刻、港澳台及海外排除、1986年推迟、旧年份不套用、跨UTC日期、重复调用与出生时间原样保留。

## 全球地点与历史时区
