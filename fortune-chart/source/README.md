## 判断口径

- 三王星继续在星盘及位置表展示；身体夹、光线夹、财富评分、恒星含义判断均只考虑传统七行星及原有相关点。三王星合恒星不再产生解读。
- 精神点：日生为上升＋太阳－月亮，夜生相反，黄经归一到 [0, 360)。福点所在星座作为衍生第一宫，第十宫看显赫，第十一宫为获取宫。
- 实现草案列出的五条财富、五条显赫及资源来源线索。严格互容要求两个不同主星双向进入对方守护星座；精神点主进入福点星座只需同星座，无需精确合相。
- 显赫指标单列核心、辅助、强化组合，不直接累加财富分，不代表正面声誉。旧规则将福点主落福点十宫直接抬至8分的路径已移除；其本命角宫等原有力量规则保留。
- 来源线索不加财富分。为使草案概念可执行，二八宫连接采用福点落本命二或八宫且二、八宫主严格互容；木星支持采用整宫相位；点主合上升采用3°。这些是实现口径，并非草案给定的额外定理。

## 新增计分（实现暂定值，草案未规定数字）

保留原五维度的基础权重与财富等级阈值。新增财富规则改为总评专项支持，直接加在五维度加权结果上，不再先加到福点维度，避免被福点10分上限及福点／三分主星取高分吞掉。最终总分限制在0–10分。

| 条件 | 总评专项加分 |
| --- | --- |
| 福点主在获取宫 | +0.6 |
| 日生木星／夜生金星在获取宫 | +1 |
| 福点主同时在获取宫、为合昼夜吉星、入庙或擢升 | +1.5 |
| 福点主与获取宫主严格守护互容 | +1.5 |
| 精神点主在获取宫 | +0.25；若与福点主为同一颗星，不重复加分 |

前三项是获取宫的嵌套支持，取最强一项；互容属于另一项结构支持，可另外计分；新增支持合计最多+2.5。福点主落获取宫在基础维度中的位置力量仍保留，专项分用于体现这一结构的财富意义，两者在界面分别说明。显赫和来源不加财富分；未命中、逆行或凶星接触不触发本专项扣分。这些数字依据草案中的核心、强组合、辅助层次设置，尚未经统计样本校准。总分每约1分可跨越一个原有财富档位，因此强组合1.5分、多项2.5分已能显著影响总评。

## 解读展示

保留精神点位置、主星与昼夜公式。其余仅展示命中的财富、显赫和来源条件；整类无命中就隐藏，不显示未命中提示、空列表或固定的衍生宫教程。每条命中包含通俗标题、本盘具体位置／主星证据、生活含义与解释边界。获取宫与福点十宫如何数，在相关命中依据中结合本盘星座解释。综合评估同步列出命中的财富依据及专项加分，不将专项分混入福点维度。
