## 判断口径

- 三王星继续在星盘及位置表展示；身体夹、光线夹、财富评分、恒星含义判断均只考虑传统七行星及原有相关点。三王星合恒星不再产生解读。
- 精神点：日生为上升＋太阳－月亮，夜生相反，黄经归一到 [0, 360)。福点所在星座作为衍生第一宫，第十宫看显赫，第十一宫为获取宫。
- 实现草案列出的五条财富、五条显赫及资源来源线索。严格互容要求两个不同主星双向进入对方守护星座；精神点主进入福点星座只需同星座，无需精确合相。
- 显赫指标单列核心、辅助、强化组合，不直接累加财富分，不代表正面声誉。旧规则将福点主落福点十宫直接抬至8分的路径已移除；其本命角宫等原有力量规则保留。
- 来源线索不加财富分。为使草案概念可执行，二八宫连接采用福点落本命二或八宫且二、八宫主严格互容；木星支持采用整宫相位；点主合上升采用3°。这些是实现口径，并非草案给定的额外定理。

## 新增计分（实现暂定值，草案未规定数字）

保留原五维度的基础权重与财富等级阈值。新增财富规则改为总评专项支持，直接加在五维度加权结果上，不再先加到福点维度，避免被福点10分上限及福点／三分主星取高分吞掉。最终总分限制在0–10分。

| 条件 | 总评专项加分 |
| --- | --- |
| 福点主在获取宫 | +0.6 |
| 日生木星／夜生金星在获取宫 | +1 |
| 福点主同时在获取宫、为合昼夜吉星、入庙或擢升 | +1.5 |
| 福点主与获取宫主严格守护互容 | +1.5 |
| 精神点主在获取宫 | +0.25；若与福点主为同一颗星，不重复加分 |

前三项是获取宫的嵌套支持，取最强一项；互容属于另一项结构支持，可另外计分；新增支持合计最多+2.5。福点主落获取宫在基础维度中的位置力量仍保留，专项分用于体现这一结构的财富意义，两者在界面分别说明。显赫和来源不加财富分；未命中、逆行或凶星接触不触发本专项扣分。这些数字依据草案中的核心、强组合、辅助层次设置，尚未经统计样本校准。总分每约1分可跨越一个原有财富档位，因此强组合1.5分、多项2.5分已能显著影响总评。

## 大陆夏令时自动时区

按用户确认后的大陆1986—1991年时段自动切换UTC+8／UTC+9，保持出生日期与钟表时间不变。1986年5月4日开始，其余年份为4月12日、4月10日、4月16日、4月15日、4月14日；结束日期依次为9月14日、13日、11日、17日、16日、15日。

春季02:00拨至03:00，02:00—02:59为不存在的钟表时间，需核对后重填。秋季02:00拨回01:00，01:00—01:59重复，表单要求选择第一次（+9）或第二次（+8）。其他日期自动判定。解析文本、手动修改日期时间、地点自动定位和最终提交均应用同一规则；计算核心也统一处理，重复调用不重复扣一小时。

地点按城市库及大陆省份名称识别，排除港澳台及海外地点，不凭经纬度矩形推测国界。未识别的地点保留所选时区；此前自动设置的大陆时区在换地点时清除。此功能使用记录在出生证明上的北京时间／北京夏令时，未扩展到各地自用地方时或海外历史夏令时。

依据：[1986年原始通知（浙江省政府公报第21—22页）](https://zjjcmspublic.oss-cn-hangzhou-zwynet-d01-a.internet.cloud.zj.gov.cn/jcms_files/jcms1/web3096/site/attach/zfgb/198608.pdf)、[1987年北京市通知](https://www.beijing.gov.cn/zhengce/zfwj/zfwj/bgtwj/201905/t20190523_73193.html)、[IANA时区数据asia](https://data.iana.org/time-zones/tzdb/asia)。未采用用户最初提供的台湾历史时段及1986年4月13日开始日期。

`node test-china-dst.mjs` 覆盖六年完整起止时刻、港澳台及海外排除、1986年推迟、旧年份不套用、跨UTC日期、重复调用与出生时间原样保留。
